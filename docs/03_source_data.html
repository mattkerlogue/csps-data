2  Source data

The original data for the Civil Service People Survey is published by the Cabinet Office. Table 2.1 provides links to each of the sources and Table 2.2 provides a summary of coverage overtime.

Table 2.2 summarises the extent of data covered, however owing to changes in publication practice over time there is not necessarily a specific file relating to each set of data in each year. Notably:

  • The 2009 to 2012 benchmarks are provided in the 2013 benchmarks file(s).
  • From 2014 onwards the SCS results are included in the demographic scores file(s).
  • From 2021 onwards the all respondents (mean) scores and organisation scores are included in the benchmark scores file.

The original data is published in a combination of CSV and Excel formats from 2009 to 2019, in 2020 in a combination of CSV and Open Document Spreadsheet (ODS) format, and only in ODS format from 2021 onwards. The file raw-data/00_data_files.yaml provides a log of all the relevant files contained within the raw-data folder, this file is also used to construct the 00_data_files.csv and 00_data_coverage.csv reference datasets.

The remaining sections of this chapter provide an overview of the data files stored in the raw-data folder of the csps-data repo.
